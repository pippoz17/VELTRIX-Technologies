# VELTRIX Technologies Website

A React + Vite corporate website for VELTRIX Technologies.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Project structure

- `src/data/siteData.js` — company details, services, products, team and page content
- `src/sections/` — homepage sections
- `src/components/` — shared navigation, footer and UI components
- `src/pages/` — product, service and legal pages
- `public/assets/` — local brand assets

## Content and publication notes

- Company contact details in `src/data/siteData.js` are the details supplied for this VELTRIX website.
- The product overview retains the core ZenXAI products currently described on the public ZenXAI website. Product availability and specifications should still be confirmed with the product team.
- Leadership names and roles are retained from the existing site content. Portraits and biographies should be added only when approved for publication.
- Project cards are illustrative capability examples, not completed client case studies.
- Career listings and talent pathways should be checked for current availability.
- Legal pages are publication placeholders until company-approved policy text is supplied.
- Regional names are indicative market references, not a claim of a staffed office in every location.

The contact form prepares an email draft using the visitor's email application. It does not send form data to a website backend.
